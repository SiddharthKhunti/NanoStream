#### Description:
NanoStream   is a high-speed, lightweight signal processing engine written in C that attempts to demonstrates the core principles of nanopore DNA basecalling. It processes raw ionic current measurements generated by Oxford Nanopore sequencing, identifies signal events corresponding to changes in the DNA moving through the nanopore, and maps these current levels to candidate k-mer sequences. The resulting base calls are reconstructed into a genomic sequence and written in standard FASTA format.

When DNA passes through a microscopic nanopore, it obstructs an electric current based on the shape and physical properties of the bases inside the pore. NanoStream focuses on developing a low-level and efficient pipeline for processing nanopore signal data, with an emphasis on memory efficiency, computational performance, and modular signal-processing algorithms.
----
### File Structure & Module Overview

`src/main.c`  : Handles command-line argument parsing (e.g., `-i` for input signals, `-o` for output FASTA file), controls execution flow, and measures total processing time/throughput.
`src/signal.c` & `include/signal.h`  : Manages reading raw signal files into dynamic memory arrays (`malloc`), sliding window signal averaging, and grouping raw float data into discrete "events."
`src/basecall.c` & `include/basecall.h`  : Holds the k-mer lookup table model, maps average electrical currents to sequence letters, and formats/writes the final output into `.fasta` format.
`Makefile`  : Configured to compile source files from `src/` using headers in `include/` with strict warning flags (`-Wall -Wextra -Werror`) and `-O3` compiler optimizations.
`data/`  : Stores sample test signals (`sample_signals.txt`) and reference ground-truth sequences (`reference_truth.fasta`).

---

### Key Features & Design Choices

1.   Pre-allocated Memory Buffers  : To avoid speed bottlenecks caused by calling `malloc()` and `free()` repeatedly inside loops, memory is allocated once at startup based on file size and cleaned up at exit.
2.   Fast Lookup Strategy  : Uses a pre-computed array structure for k-mer matching, allowing O(1) constant-time or O(log N) binary search matching rather than scanning lists sequentially.
3.   Modular Architecture  : Decouples signal parsing (`signal.c`) from sequence decoding (`basecall.c`), keeping the codebase clean, scalable, and easy to debug with zero memory leaks (`valgrind`).

### Step-by-Step Setup & Execution

1. Navigate to the Project Directory
```bash
cd nanostream

2. Ensure the binary destination directory exists before compiling
```bash
mkdir -p bin

3. Compile the project provided by the Makefile
```bash
make

4. Run bin/nanostream by providing raw signal inputs via the -i flag and setting the target FASTA output path via the -o flag:
```bash
./bin/nanostream -i data/sample_signals.txt -o my_output.fasta

5. Diplay the basecalle DNA sequence generated by the pipeline
```bash
cat my_output.fasta

6. Confirm the operation runs free of memory leaks
```bash
valgrind --leak-check=full ./bin/nanostream -i data/sample_signals.txt -o my_output.

7. Clean build artifacts after use
```bash
make clean
